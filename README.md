# Control Flow - IBM Full Stack JavaScript Developer Course

This repository contains practical exercises from the **IBM Full Stack JavaScript Developer** course available on Coursera. The exercises focus on fundamental JavaScript concepts, including control structures, conditionals, and DOM manipulation.

## 📚 Course Content

### Modules Included:
- **Control Flow and Conditional Structures**
- **DOM Manipulation**
- **Functions and Event Listeners**
- **Basic Mathematical Calculations**

## 🚀 Implemented Exercises

### 1. Control Flow (`control_flow/`)
**Concepts Practiced:**
- `if/else` and `else if` statements
- `switch` statements
- Ternary operators
- Nested conditional logic

**Features:**
- Role-based authorization system
- User access management
- Authentication validation

### 2. Interactive Followers Counter (`followersCount/`)
**Concepts Practiced:**
- DOM manipulation
- Event listeners (`onclick`, `mousemove`)
- Interactive functions
- User alerts and feedback

**Features:**
- Dynamic followers counter
- Interactive buttons (Follow/Restart)
- Achievement alerts (10 and 20 followers)
- Mouse coordinates tracking

### 3. Area Calculator (`calculate/`)
**Concepts Practiced:**
- User input handling
- Mathematical calculations
- Input validation
- Form manipulation

**Features:**
- Rectangle area calculation
- Positive number validation
- Intuitive user interface

### 4. Grocery Calculator (`work/`)
**Concepts Practiced:**
- Arithmetic operations
- Array handling
- Total and average calculations
- Number formatting

**Features:**
- Grocery shopping calculation system
- Total and average calculations
- Multiple product handling

## 🚀 How to Run

1. **Clone or download** the repository
2. **Open** any `.html` file in your web browser
3. **Open developer tools** (F12) to see console outputs
4. **Interact** with page elements according to each exercise

### Example:
```bash
# Navigate to project directory
cd controlFlow

# Open a specific exercise
# Option 1: Double-click the HTML file
# Option 2: From terminal (Linux)
xdg-open control_flow/control_flow.html
```

### Authorization Exercise - Dietary Services
**File:** `control_flow/scripts/control_flow_wk1.js`

Authorization system for an organization offering dietary services:
- **Employees**: Full access to dietary services
- **Enrolled Members**: Full access + individual dietitian consultation
- **Subscribers**: Partial access to dietary services
- **Non-Subscribers**: Registration required for access
